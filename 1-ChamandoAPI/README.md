# 📃 Aula 01

## 🛠 Para rodar em sua máquina:

1. Nescessário a instalação dos pacotes:
``openIa`` e ``dotenv``

2. Nescessario a criação do arquivo ``.env``
3. A configuração de uma ``API_KEY=""`` com sua chave pessoal dentro do ``.env``

- Pode ser usado como exemplo para a criação do ``.env`` o arquivo ``.envExemple``
